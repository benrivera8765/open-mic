# Screenshots

Captures of the app taken during testing on 2026-11-17 (and 18 for the two `stage-page-*` files) on Windows 11 (WebView2), reduced
for the README: scaled to 1200 x 750 with a Lanczos filter (from 1440 x 900; `key-dial.png`
is a 640 x 360 crop, not scaled) and, for the skinned views, colour depth reduced to 6 bits
per channel to keep each file under 400 KB.
The two `stage-page-*` captures (1440 x 900) are scaled to 1152 x 720 in headless Edge (`imageSmoothingQuality` "high") with 5 bits per channel, for the same size limit. No other editing. They show the Windows build; the Mac app has not run yet.

| file | what it shows | captured from |
|---|---|---|
| `library.png` | the library as jukebox title strips: our generated test songs and the demo song | the real app (a release build) driven over WebView2 DevTools on the silent null audio device |
| `stage.png` | singing the demo song at +1 semitone with the scrolling ticker (the default before D-218, now Settings > Lyrics > "Scrolling ticker"): the marker sits on the letter being sung, sung letters turn pink (the colours before D-218) | the real app, same run |
| `stage-page-wipe.png` | the page display (the default since D-218, 18 Nov 2026): the line being sung stands still and turns gold word by word, with the progress needle (D-219) on the gold/white boundary half way through the second "twinkle"; the next line waits underneath, smaller | the real app (release build) driven over WebView2 DevTools on the silent null device (`app/ui/scripts/real-app-page-needle.mjs`), 18 Nov 2026 |
| `stage-page-lead-in.png` | the page display before a line after a pause: the gold lead-in bar left of the line runs out when the first word starts (taken before the progress needle was added) | the real app (`real-app-page-lyrics.mjs`), 18 Nov 2026 |
| `key-dial.png` | the key dial and the key label "C major → D♭ major (+1)" | crop of the real app's 3840 x 2160 capture in the same run (same song, key and position) |
| `studio.png` | the Studio after a queue: one song made, a corrupt test file failed with a plain message | the real app in the end-to-end test, after it made the song on the RTX 5070 Ti |
| `stage-studio-song.png` | singing a song the Studio made, with aligned lyrics | the real app in the end-to-end test |
| `plain-mode.png` | the plain look (jukebox skin off) | the UI in headless Microsoft Edge with the app's mock back end (`npm run screenshots`) |
