Third-party licence and notice texts
====================================

Generated by scripts/gen-third-party.sh from Cargo.lock, app/ui/package-lock.json and the Studio runtime; do not edit by hand. MIT, BSD and Apache-2.0 require these notices to travel with the binaries. Which component uses which licence, and whether it is compatible with GPL-3.0-or-later: THIRD_PARTY_LICENSES.md.

  rust-crates.txt      every Rust crate linked into the app, jukeoke-cli or sck_probe
  npm-packages.txt     the npm packages in the UI bundle and the code the build emits
  python-packages.txt  Studio packages whose wheels ship no licence file
  vendored.txt         Rubber Band's COPYING
  MISSING.txt          what could not be found, and what is relied on instead

The fonts' SIL Open Font License texts are in Licenses/fonts/ on the stick (app/ui/src/assets/fonts/*/OFL.txt in the repository).
